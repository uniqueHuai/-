# 过滤器

写过滤器类继承Filter接口实现里面的方法，doFilter（）放行请求是关键

或者继承OncePerRequestFilter，实现方法

再写入一个拦截器配置类FilterRegistrationBean可以实现部分拦截

```
@Slf4j
@Component
//这个是过滤全部的请求的，要想过滤部分请求可以再写入一个过滤器配置类
public class MyFilter implements Filter {
    @Override
    public void init(FilterConfig filterConfig) throws ServletException {
        Filter.super.init(filterConfig);
    }

    @Override
    public void doFilter(ServletRequest servletRequest, ServletResponse servletResponse, FilterChain filterChain) throws IOException, ServletException {
        log.info("MyFilter,执行过滤");
        // 必须调用 filterChain.doFilter() 放行请求！
        filterChain.doFilter(servletRequest, servletResponse);
    }

    @Override
    public void destroy() {
        Filter.super.destroy();
    }
}
```

```
@Configuration
public class FilterConfig {
    @Bean
    public FilterRegistrationBean<MyFilter> myFilterRegistration() {
        FilterRegistrationBean<MyFilter> registration = new FilterRegistrationBean<>();
        registration.setFilter(new MyFilter());
        registration.addUrlPatterns("/*"); // 拦截所有路径
        registration.setOrder(1); // 设置执行顺序
        // 排除 /admin 开头的路径
        registration.addInitParameter("exclusions", "/admin/*");
        return registration;
    }
}
```

# Springsecurity

底层其实就是过滤器链，可在过滤链里面实现

- 自动处理登录表单提交
- 管理Session
- 防止CSRF攻击
- 方法级权限控制（@PreAuthorize）
- 整合OAuth2等认证协议

```
@Configuration
@EnableWebSecurity // 启用Spring Security
public class WebSecurityConfig {

     // 配置安全过滤链
    @Bean
    public SecurityFilterChain securityFilterChain(HttpSecurity http) throws Exception {
        http
                .csrf(csrf -> csrf.disable()) // 禁用CSRF，因为JWT是无状态的
                .sessionManagement(session -> session.sessionCreationPolicy(SessionCreationPolicy.STATELESS)) // 使用无状态session
                .authorizeHttpRequests(authorize -> authorize
                        .requestMatchers("/", "/login", "/auth/login", "/auth/register", "/css/**", "/js/**").permitAll() // 允许所有人访问这些路径
                        .requestMatchers("/admin/**").hasRole("ADMIN")
                        .anyRequest().authenticated() // 其他所有请求需要认证，这个只是认证有没有带token，所有请求都要再经过一次过滤器的
                )
                .addFilterBefore(jwtAuthenticationFilter(), UsernamePasswordAuthenticationFilter.class) // 添加JWT过滤器
                .logout(logout -> logout
                        .logoutSuccessUrl("/login?logout") // 注销后跳转到登录页
                        .permitAll()
                );

        return http.build();
    }

    @Bean
    public JwtAuthenticationFilter jwtAuthenticationFilter() {
        return new JwtAuthenticationFilter();
    }
    }
```

# 拦截器

拦截器首先要继承HandlerInterceptor接口，实现里面的方法，preHandle方法是关键，返回结果是false就拦截了。到现在这个只是拦截器的实现，还没写它要拦截哪些路径和请求。要实现这一步还要写一个拦截器配置类继承WebMvcConfigurer接口，并且重写addInterceptors方法。

```
public class LoginInterceptor implements HandlerInterceptor {

    @Override
    public boolean preHandle(HttpServletRequest request, HttpServletResponse response, Object handler) throws Exception {

        //这里可以写入拦截器具体要实现的业务操作功能，一般用于验证
        return HandlerInterceptor.super.preHandle(request, response, handler);
    }

    @Override
    public void postHandle(HttpServletRequest request, HttpServletResponse response, Object handler, ModelAndView modelAndView) throws Exception {
        log.info("postHandle,执行controller之后，视图渲染之前");
        HandlerInterceptor.super.postHandle(request, response, handler, modelAndView);
    }

    @Override
    public void afterCompletion(HttpServletRequest request, HttpServletResponse response, Object handler, Exception ex) throws Exception {
        log.info("afterCompletion,整个流程完成之后");
        HandlerInterceptor.super.afterCompletion(request, response, handler, ex);
    }
}
```

```
@Configuration
public class WebConfig implements WebMvcConfigurer {

    @Override
    public void addInterceptors(InterceptorRegistry registry) {
        // 注册登录拦截器
        registry.addInterceptor(new LoginInterceptor())
                .addPathPatterns("/**") // 拦截所有路径
                .excludePathPatterns( // 添加不拦截路径
                        "/login",  // 登录接口
                        "/swagger-resources/**",  // swagger
                        "/webjars/**",  // swagger
                        "/v2/**",  // swagger
                        "/swagger-ui.html/**",  // swagger
                        "/doc.html/**",  // knife4j
                        "/error"  // 错误页面
                )
                .order(1); // 设置拦截器执行顺序
    }
}
```

# jwt

这是一种认证方案，确保后续能否继续访问对应的资源

写入依赖，并且写配置类，然后实现jwt注册、验证、解析方法就行了

```
public class JwtUtils {
    /**
     * JWT密钥，用于签名和验证JWT
     * 注意：在生产环境中应该使用更安全的方式存储密钥，例如环境变量或配置文件
     */
    // 使用Keys.secretKeyFor()生成符合安全要求的密钥
    private static final SecretKey SECRET_KEY = Keys.secretKeyFor(SignatureAlgorithm.HS256);
    
    /**
     * JWT过期时间，单位毫秒
     * 当前设置为24小时
     */
    private static final long EXPIRATION_TIME = 86400000; // 24小时

    /**
     * 生成JWT令牌
     * @param username 用户名
     * @return 生成的JWT令牌字符串
     */
    public static String generateToken(String username) {
        return Jwts.builder()
                .setSubject(username) // 设置主题（用户名）
                .setIssuedAt(new Date()) // 设置签发时间
                .setExpiration(new Date(System.currentTimeMillis() + EXPIRATION_TIME)) // 设置过期时间
                .signWith(SECRET_KEY) // 直接使用SecretKey对象
                .compact(); // 生成JWT字符串
    }

    /**
     * 验证JWT令牌的有效性
     * @param token 待验证的JWT令牌
     * @return 如果令牌有效返回true，否则返回false
     */
    public static boolean validateToken(String token) {
        try {
            Jwts.parserBuilder()
                .setSigningKey(SECRET_KEY) // 设置用于验证的密钥
                .build()
                .parseClaimsJws(token); // 解析并验证令牌
            return true; // 验证成功
        } catch (Exception e) {
            return false; // 验证失败
        }
    }

    /**
     * 从JWT令牌中提取用户名
     * @param token JWT令牌
     * @return 令牌中的用户名
     */
    public static String getUsernameFromToken(String token) {
        return Jwts.parserBuilder()
                .setSigningKey(SECRET_KEY) // 设置用于解析的密钥
                .build()
                .parseClaimsJws(token) // 解析令牌
                .getBody() // 获取载荷
                .getSubject(); // 获取主题（用户名）
    }
}
```
