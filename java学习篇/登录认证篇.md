# 登录认证篇

## 整体请求流程

```
请求 → 过滤器（Filter）→ DispatcherServlet → 拦截器 preHandle → Controller → 拦截器 postHandle → 拦截器 afterCompletion → 响应
```

> [!info] **三个层次的拦截机制**
> - **过滤器（Filter）**：最外层，在 Servlet 之前，**粗粒度**过滤
> - **拦截器（Interceptor）**：SpringMVC 内部，在 Controller 前后，**细粒度**控制
> - **AOP**：可以切入到具体的方法内部

---

## 过滤器（Filter）

### 作用

对请求和响应进行**全局的、粗粒度**的处理，在请求到达 Servlet 之前进行过滤。典型应用：**字符编码、CORS 跨域、JWT 验证、请求日志**。

### 实现方式

#### 方式一：实现 Filter 接口

```java
@Slf4j
@Component  // 拦截所有请求
public class MyFilter implements Filter {

    @Override
    public void init(FilterConfig filterConfig) {
        log.info("MyFilter 初始化");
    }

    @Override
    public void doFilter(ServletRequest request, ServletResponse response,
                         FilterChain chain) throws IOException, ServletException {
        log.info("MyFilter 执行过滤");
        // ⚠️ 必须放行，否则请求被阻断
        chain.doFilter(request, response);
    }

    @Override
    public void destroy() {
        log.info("MyFilter 销毁");
    }
}
```

#### 方式二：继承 OncePerRequestFilter（推荐）

```
@Slf4j
@Component
public class JwtAuthFilter extends OncePerRequestFilter {
    @Override
    protected void doFilterInternal(HttpServletRequest request,
                                    HttpServletResponse response,
                                    FilterChain chain) throws ... {
        // 业务逻辑
        chain.doFilter(request, response);
    }
}
```

> [!tip] **`OncePerRequestFilter`  vs  `Filter`**
> - `OncePerRequestFilter` 确保每个请求**只经过一次过滤**（即使请求被转发）
> - 推荐用于 JWT 认证等场景

#### 过滤器配置类（控制拦截路径）

```java
@Configuration
public class FilterConfig {
    @Bean
    public FilterRegistrationBean<MyFilter> myFilterRegistration() {
        FilterRegistrationBean<MyFilter> registration = new FilterRegistrationBean<>();
        registration.setFilter(new MyFilter());
        registration.addUrlPatterns("/*");          // 拦截所有路径
        registration.setOrder(1);                   // 执行顺序（越小越先执行）
        registration.addInitParameter("exclusions", "/admin/*");
        return registration;
    }
}
```

## SpringSecurity

Spring Security 底层就是**过滤器链**，在过滤器链中实现认证和授权功能。

> 详见 [[SpringSecurity]]

### 核心能力

- ✅ 自动处理登录表单提交
- ✅ 管理 Session
- ✅ 防止 CSRF 攻击
- ✅ 方法级权限控制（`@PreAuthorize`）
- ✅ 整合 OAuth2 等认证协议

### 基本配置示例

```java
@Configuration
@EnableWebSecurity
public class WebSecurityConfig {

    @Bean
    public SecurityFilterChain securityFilterChain(HttpSecurity http) throws Exception {
        http
            .csrf(csrf -> csrf.disable())
            .sessionManagement(session ->
                session.sessionCreationPolicy(SessionCreationPolicy.STATELESS))
            .authorizeHttpRequests(auth -> auth
                .requestMatchers("/", "/login", "/auth/**", "/css/**", "/js/**").permitAll()
                .requestMatchers("/admin/**").hasRole("ADMIN")
                .anyRequest().authenticated()
            )
            .addFilterBefore(jwtAuthenticationFilter(),
                             UsernamePasswordAuthenticationFilter.class)
            .logout(logout -> logout.logoutSuccessUrl("/login?logout").permitAll());
        return http.build();
    }

    @Bean
    public JwtAuthenticationFilter jwtAuthenticationFilter() {
        return new JwtAuthenticationFilter();
    }
}
```

## 拦截器（Interceptor）

### 作用

拦截器是 SpringMVC 提供的机制，在 **Controller 方法前后**进行细粒度拦截。典型应用：**登录校验、权限验证、日志记录、性能监控**。

### 实现方式

```java
@Slf4j
public class LoginInterceptor implements HandlerInterceptor {

    /**
     * 在 Controller 方法执行前调用
     * 返回 true 放行，false 拦截
     */
    @Override
    public boolean preHandle(HttpServletRequest request,
                             HttpServletResponse response,
                             Object handler) throws Exception {
        log.info("preHandle — 进入 Controller 之前");
        return true; // false 则拦截请求
    }

    /**
     * 在 Controller 方法执行后、视图渲染前调用
     */
    @Override
    public void postHandle(HttpServletRequest request,
                           HttpServletResponse response,
                           Object handler, ModelAndView modelAndView) throws Exception {
        log.info("postHandle — Controller 执行完毕，视图渲染之前");
    }

    /**
     * 在整个请求完成后调用（视图渲染之后）
     */
    @Override
    public void afterCompletion(HttpServletRequest request,
                                HttpServletResponse response,
                                Object handler, Exception ex) throws Exception {
        log.info("afterCompletion — 整个流程完成");
    }
}
```

### 拦截器配置类（指定拦截路径）

```java
@Configuration
public class WebConfig implements WebMvcConfigurer {

    @Override
    public void addInterceptors(InterceptorRegistry registry) {
        registry.addInterceptor(new LoginInterceptor())
                .addPathPatterns("/**")                     // 拦截所有路径
                .excludePathPatterns(                       // 白名单
                    "/login",
                    "/swagger-resources/**",                // swagger
                    "/webjars/**",
                    "/v2/**",
                    "/swagger-ui.html/**",
                    "/doc.html/**",                         // knife4j
                    "/error"
                )
                .order(1);  // 执行顺序
    }
}
```

## JWT（JSON Web Token）

### 什么是 JWT

JWT 是一种**无状态的认证方案**，服务端不需要保存 Session 信息，认证信息 encoded 在 Token 本身中。

> [!info] **JWT 结构**
> `header.payload.signature`
> - **Header**：算法类型（HS256）
> - **Payload**：用户信息、过期时间等（**不要放敏感信息**）
> - **Signature**：对前两部分的签名，防止篡改

### 核心工具类

```java
public class JwtUtils {

    // 密钥（生产环境应放在配置文件中）
    private static final SecretKey SECRET_KEY =
        Keys.secretKeyFor(SignatureAlgorithm.HS256);

    // 过期时间：24小时
    private static final long EXPIRATION_TIME = 86400000;

    /** 生成令牌 */
    public static String generateToken(String username) {
        return Jwts.builder()
                .setSubject(username)
                .setIssuedAt(new Date())
                .setExpiration(new Date(System.currentTimeMillis() + EXPIRATION_TIME))
                .signWith(SECRET_KEY)
                .compact();
    }

    /** 验证令牌 */
    public static boolean validateToken(String token) {
        try {
            Jwts.parserBuilder()
                .setSigningKey(SECRET_KEY)
                .build()
                .parseClaimsJws(token);
            return true;
        } catch (Exception e) {
            return false;
        }
    }

    /** 从令牌中提取用户名 */
    public static String getUsernameFromToken(String token) {
        return Jwts.parserBuilder()
                .setSigningKey(SECRET_KEY)
                .build()
                .parseClaimsJws(token)
                .getBody()
                .getSubject();
    }
}
```

### JWT 认证流程

```
① 用户登录 → 服务端验证用户名密码 → 生成 JWT 返回
② 客户端存储 JWT（localStorage / Cookie）
③ 后续请求在 Header 中携带：Authorization: Bearer <token>
④ 过滤器拦截请求 → 解析并验证 JWT → 放行 / 拒绝
```

## 四者关系总结

| 机制 | 层级 | 粒度 | 典型用途 |
|------|:----:|:----:|----------|
| **Filter** | Servlet 容器 | 粗粒度 | 编码、CORS、JWT 解析 |
| **Interceptor** | SpringMVC | 中粒度 | 登录校验、权限、日志 |
| **SpringSecurity** | 过滤器链封装 | 认证/授权 | 安全框架 |
| **AOP** | Spring 容器 | 细粒度 | 方法级增强 |

> [!tip] **执行顺序**
> **Filter → SpringSecurity → Interceptor.preHandle → Controller → Interceptor.postHandle → Interceptor.afterCompletion**
