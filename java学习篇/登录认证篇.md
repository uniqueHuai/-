# 登录认证篇

## 一、整体请求流程

```
请求 → 过滤器（Filter）→ DispatcherServlet → 拦截器 preHandle → Controller → 拦截器 postHandle → 拦截器 afterCompletion → 响应
```

> [!info] **三个层次的拦截机制**
> - **过滤器（Filter）**：最外层，在 Servlet 之前，**粗粒度**过滤
> - **拦截器（Interceptor）**：SpringMVC 内部，在 Controller 前后，**中粒度**控制
> - **AOP**：可以切入到具体的方法内部，**细粒度**增强

---

## 二、过滤器（Filter）

### 作用

对请求和响应进行**全局的、粗粒度**的处理，在请求到达 Servlet 之前进行过滤。典型应用：**字符编码、CORS 跨域、JWT 验证、请求日志**。

### 实现方式

#### 方式一：实现 `Filter` 接口

```java
@Slf4j
@Component  // 拦截所有请求
public class MyFilter implements Filter {

    @Override
    public void init(FilterConfig filterConfig) {
        log.info("MyFilter 初始化");
    }

    @Override
    public void doFilter(ServletRequest request, ServletResponse response,
                         FilterChain chain) throws IOException, ServletException {
        log.info("MyFilter 执行过滤");
        // ⚠️ 必须放行，否则请求被阻断
        chain.doFilter(request, response);
    }

    @Override
    public void destroy() {
        log.info("MyFilter 销毁");
    }
}
```

#### 方式二：继承 `OncePerRequestFilter`（⭐ 推荐）

```java
@Slf4j
@Component
public class JwtAuthFilter extends OncePerRequestFilter {
    @Override
    protected void doFilterInternal(HttpServletRequest request,
                                    HttpServletResponse response,
                                    FilterChain chain) throws ServletException, IOException {
        // JWT 解析、校验等业务逻辑
        chain.doFilter(request, response);
    }
}
```

> [!tip] **`OncePerRequestFilter` vs `Filter`**
> - `OncePerRequestFilter` 确保每个请求**只经过一次过滤**（即使请求被转发）
> - 推荐用于 JWT 认证等场景，SpringSecurity 的 JWT 过滤器也常基于此类实现

#### 过滤器配置类（控制拦截路径）

```java
@Configuration
public class FilterConfig {
    @Bean
    public FilterRegistrationBean<MyFilter> myFilterRegistration() {
        FilterRegistrationBean<MyFilter> registration = new FilterRegistrationBean<>();
        registration.setFilter(new MyFilter());
        registration.addUrlPatterns("/*");          // 拦截所有路径
        registration.setOrder(1);                   // 执行顺序（越小越先执行）
        registration.addInitParameter("exclusions", "/admin/*");
        return registration;
    }
}
```

## 三、SpringSecurity

### 3.1 概念

Spring Security 本质上就是一串**过滤器链（Filter Chain）**，通过在 Servlet 进入 Controller **之前**拦截请求，实现**认证（Authentication）和授权（Authorization）**。

```
请求 → 过滤器链（依次执行多个过滤器）→ 若全部通过 → 到达 DispatcherServlet → Controller
```

> [!info] **核心能力**
> - ✅ 自动处理登录表单提交
> - ✅ 管理 Session
> - ✅ 防止 CSRF 攻击
> - ✅ 方法级权限控制（`@PreAuthorize`）
> - ✅ 整合 OAuth2 等认证协议

### 3.2 使用步骤

#### 步骤一：引入依赖

```xml
<dependency>
    <groupId>org.springframework.boot</groupId>
    <artifactId>spring-boot-starter-security</artifactId>
</dependency>
```

> [!tip] **默认行为**
> 若未自定义 `@EnableWebSecurity` 或 `SecurityFilterChain`，Spring Boot 会自动启用默认安全配置（跳转内置登录页面）。

#### 步骤二：重写 Security 配置类

```java
@Configuration
@EnableWebSecurity  // 启用 Spring Security
public class SecurityConfig {

    @Bean
    public SecurityFilterChain securityFilterChain(HttpSecurity http) throws Exception {
        http
            .csrf(csrf -> csrf.disable())                           // 禁用 CSRF（JWT 无状态）
            .sessionManagement(session ->
                session.sessionCreationPolicy(SessionCreationPolicy.STATELESS)) // 无状态 Session
            .authorizeHttpRequests(auth -> auth
                .requestMatchers("/", "/login", "/auth/**", "/css/**", "/js/**").permitAll()
                .requestMatchers("/admin/**").hasRole("ADMIN")
                .anyRequest().authenticated()
            )
            .addFilterBefore(jwtAuthFilter(), UsernamePasswordAuthenticationFilter.class)
            .logout(logout -> logout
                .logoutSuccessUrl("/login?logout")
                .permitAll()
            );

        return http.build();
    }

    @Bean
    public JwtAuthenticationFilter jwtAuthFilter() {
        return new JwtAuthenticationFilter();
    }
}
```

#### 步骤三：编写 JWT 配置类

配置 JWT 相关的 Bean：

| 配置项 | 说明 |
|--------|------|
| **密钥（SecretKey）** | 用于签名和验证令牌 |
| **过期时间** | 如 24 小时 |
| **`generateToken(username)`** | 生成令牌 |
| **`validateToken(token)`** | 验证令牌 |
| **`getUsernameFromToken(token)`** | 从令牌提取用户名 |

> JWT 的完整工具类实现详见下方的 [[登录认证篇#五、JWT（JSON Web Token）|JWT 章节]]。

#### 步骤四：编写 JWT 认证过滤器

```java
@Component
public class JwtAuthenticationFilter extends OncePerRequestFilter {

    @Override
    protected void doFilterInternal(HttpServletRequest request,
                                    HttpServletResponse response,
                                    FilterChain filterChain)
            throws ServletException, IOException {
        // 1. 从请求头提取 token
        String token = extractToken(request);

        // 2. 验证 token
        if (token != null && JwtUtils.validateToken(token)) {
            // 3. 解析用户名并存入 SecurityContextHolder
            String username = JwtUtils.getUsernameFromToken(token);
            UsernamePasswordAuthenticationToken auth =
                new UsernamePasswordAuthenticationToken(username, null, new ArrayList<>());
            SecurityContextHolder.getContext().setAuthentication(auth);
        }

        // 4. 放行
        filterChain.doFilter(request, response);
    }

    private String extractToken(HttpServletRequest request) {
        String header = request.getHeader("Authorization");
        if (header != null && header.startsWith("Bearer ")) {
            return header.substring(7);
        }
        return null;
    }
}
```

### 3.3 核心组件总结

| 组件 | 作用 | 位置 |
|------|------|:----:|
| **`SecurityFilterChain`** | 配置安全过滤规则 | 配置类 |
| **`JwtAuthenticationFilter`** | 从请求中提取并验证 JWT | 过滤器链 |
| **`SecurityContextHolder`** | 存储当前登录用户信息（线程本地） | 线程级别 |
| **`@PreAuthorize`** | 方法级别权限控制（如 `hasRole('ADMIN')`） | Service / Controller |

> [!tip] **一句话记忆**
> Spring Security = **过滤器链** + **认证** + **授权**，通过在 Servlet 前拦截请求来实现安全控制。

## 四、拦截器（Interceptor）

### 作用

拦截器是 SpringMVC 提供的机制，在 **Controller 方法前后**进行细粒度拦截。典型应用：**登录校验、权限验证、日志记录、性能监控**。

### 实现方式

```java
@Slf4j
public class LoginInterceptor implements HandlerInterceptor {

    /** 在 Controller 方法执行前调用，返回 true 放行，false 拦截 */
    @Override
    public boolean preHandle(HttpServletRequest request,
                             HttpServletResponse response,
                             Object handler) throws Exception {
        log.info("preHandle — 进入 Controller 之前");
        return true;
    }

    /** 在 Controller 方法执行后、视图渲染前调用 */
    @Override
    public void postHandle(HttpServletRequest request,
                           HttpServletResponse response,
                           Object handler, ModelAndView modelAndView) throws Exception {
        log.info("postHandle — Controller 执行完毕，视图渲染之前");
    }

    /** 在整个请求完成后调用（视图渲染之后） */
    @Override
    public void afterCompletion(HttpServletRequest request,
                                HttpServletResponse response,
                                Object handler, Exception ex) throws Exception {
        log.info("afterCompletion — 整个流程完成");
    }
}
```

### 拦截器配置类（指定拦截路径）

```java
@Configuration
public class WebConfig implements WebMvcConfigurer {

    @Override
    public void addInterceptors(InterceptorRegistry registry) {
        registry.addInterceptor(new LoginInterceptor())
                .addPathPatterns("/**")                     // 拦截所有路径
                .excludePathPatterns(                       // 白名单
                    "/login",
                    "/swagger-resources/**",                // swagger
                    "/webjars/**",
                    "/v2/**",
                    "/swagger-ui.html/**",
                    "/doc.html/**",                         // knife4j
                    "/error"
                )
                .order(1);  // 执行顺序
    }
}
```

## 五、JWT（JSON Web Token）

### 5.1 什么是 JWT

JWT 是一种**无状态的认证方案**，服务端不需要保存 Session 信息，认证信息编码在 Token 本身中。

> [!info] **JWT 结构：`header.payload.signature`**
> | 部分 | 内容 | 说明 |
> |:----:|------|------|
> | **Header** | `{"alg":"HS256","typ":"JWT"}` | 算法类型和 Token 类型 |
> | **Payload** | `{"sub":"admin","iat":...,"exp":...}` | 用户信息、签发时间、过期时间（**不要放敏感信息**） |
> | **Signature** | 对前两部分的签名 | 使用密钥对 header + payload 进行签名，防止篡改 |

### 5.2 核心工具类

```java
public class JwtUtils {

    // 密钥（生产环境应放在配置文件中）
    private static final SecretKey SECRET_KEY =
        Keys.secretKeyFor(SignatureAlgorithm.HS256);

    // 过期时间：24小时
    private static final long EXPIRATION_TIME = 86400000;

    /** 生成令牌 */
    public static String generateToken(String username) {
        return Jwts.builder()
                .setSubject(username)
                .setIssuedAt(new Date())
                .setExpiration(new Date(System.currentTimeMillis() + EXPIRATION_TIME))
                .signWith(SECRET_KEY)
                .compact();
    }

    /** 验证令牌 */
    public static boolean validateToken(String token) {
        try {
            Jwts.parserBuilder()
                .setSigningKey(SECRET_KEY)
                .build()
                .parseClaimsJws(token);
            return true;
        } catch (ExpiredJwtException | UnsupportedJwtException |
                 MalformedJwtException | IllegalArgumentException e) {
            return false;
        }
    }

    /** 从令牌中提取用户名 */
    public static String getUsernameFromToken(String token) {
        return Jwts.parserBuilder()
                .setSigningKey(SECRET_KEY)
                .build()
                .parseClaimsJws(token)
                .getBody()
                .getSubject();
    }
}
```

### 5.3 JWT 认证流程

```
① 用户登录 → 服务端验证用户名密码 → 生成 JWT 返回
② 客户端存储 JWT（localStorage / Cookie）
③ 后续请求在 Header 中携带：Authorization: Bearer <token>
④ SpringSecurity 过滤器链中的 JwtAuthenticationFilter 拦截请求
   → 提取并验证 JWT → 存入 SecurityContextHolder → 放行 / 拒绝
```

> [!warning] **JWT 注意事项**
> - Token 一旦签发，在过期前**无法主动撤销**（无状态特性），若需提前失效可借助**黑名单机制**
> - Payload 是 Base64 编码**非加密**，**不要存放密码、手机号等敏感信息**
> - 密钥应放在配置文件或环境变量中，**不要硬编码在代码里**

## 六、各机制对比与执行顺序

### 6.1 对比总结

| 机制 | 所属层级 | 粒度 | 典型用途 |
|------|:--------:|:----:|----------|
| **Filter** | Servlet 容器 | 🔵 粗粒度 | 字符编码、CORS、JWT 解析 |
| **SpringSecurity** | 过滤器链封装 | 🟢 认证/授权 | 安全框架（认证 + 授权 + CSRF） |
| **Interceptor** | SpringMVC | 🟡 中粒度 | 登录校验、权限校验、日志 |
| **AOP** | Spring 容器 | 🔴 细粒度 | 方法级增强（如 @Transactional） |

### 6.2 执行顺序

```
Filter → SpringSecurity 过滤器链 → Interceptor.preHandle → Controller
 → Interceptor.postHandle → Interceptor.afterCompletion → 响应
```

### 6.3 经典配合实践

| 层级 | 职责 | 实现 |
|:----:|------|------|
| ① **Filter** | 统一字符编码、CORS 跨域 | `CharacterEncodingFilter`、`CorsFilter` |
| ② **SpringSecurity** | JWT 令牌认证、接口权限控制、CSRF 防护 | `SecurityFilterChain` + `JwtAuthenticationFilter` |
| ③ **Interceptor** | 记录请求日志、统计接口耗时、补充业务权限校验 | `HandlerInterceptor` |
| ④ **AOP** | 方法级别操作日志、事务管理 | `@Around` + 自定义注解 |
