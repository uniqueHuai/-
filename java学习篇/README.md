## 📚 推荐学习顺序

### Phase 1：Java 语言基础

#### ① [[Java基础与进阶篇]] ⭐ 起点

| 项目 | 说明 |
|:----|:----|
| **前置知识** | 无（零基础起点） |
| **内容** | 语法、OOP、集合、异常、泛型、反射、IO/NIO、Lambda、Stream、并发编程、JUC、JMM |
| **目标** | 掌握 Java 核心语法和常用 API，理解面向对象思想，具备并发编程基础 |
| **一句话** | **所有笔记的基石，必须最先学习** |

> [!note] 这篇笔记覆盖了 Java 面试中最核心的知识点（集合、并发、JUC），值得反复翻阅。

---

### Phase 2：Java 进阶

#### ② [[JVM篇]]

| 项目 | 说明 |
|:----|:----|
| **前置知识** | [[Java基础与进阶篇]]（需要理解类加载、内存中的对象布局等概念） |
| **内容** | 类加载机制、运行时数据区、GC 算法与收集器、JIT 优化、class 文件结构 |
| **目标** | 深入理解 Java 程序在 JVM 中的执行过程，掌握内存调优和 GC 调优基础 |
| **一句话** | 理解 JVM 是**从"会用 Java"到"懂 Java"的关键一步** |

> [!tip] 建议在学习 Java 基础的**并发与内存相关章节后**立即学习 JVM，两者知识互通。

---

### Phase 3：企业级框架

先掌握 [[SpringBoot篇]]，再根据方向选择 登录认证 或 微服务。

#### ③ [[SpringBoot篇]] ⭐ 核心

| 项目 | 说明 |
|:----|:----|
| **前置知识** | [[Java基础与进阶篇]]（尤其注解、反射、IOC/AOP 思想） |
| **内容** | 自动配置原理、@Conditional、@ConfigurationProperties、自定义 Starter、Actuator |
| **目标** | 掌握 Spring Boot 核心机制，能够独立搭建和配置企业级应用 |
| **一句话** | **Spring Boot 是 Java 后端的"事实标准"，后续两篇笔记都依赖它** |

---

#### ④ [[登录认证篇]]

| 项目 | 说明 |
|:----|:----|
| **前置知识** | [[Java基础与进阶篇]]（Filter、AOP 思想）+ [[SpringBoot篇]]（Spring Security 配置） |
| **内容** | Filter、Spring Security、JWT、Interceptor、AOP、执行顺序 |
| **目标** | 掌握企业级登录认证方案的完整实现链路 |
| **一句话** | 大部分后端项目都需要认证授权，**实用性极强** |

---

#### ⑤ [[SpringCloud篇]]

| 项目 | 说明 |
|:----|:----|
| **前置知识** | [[Java基础与进阶篇]] + [[SpringBoot篇]] |
| **内容** | Nacos（注册+配置中心）、OpenFeign、Sentinel、Gateway、Seata |
| **目标** | 理解微服务架构核心组件，具备分布式系统开发基础 |
| **一句话** | **在掌握 Spring Boot 之后学习**，是走向微服务架构的第一站 |

> [!tip] ④ 和 ⑤ 可以**并行学习**，两者不互相依赖，但都依赖 ③ SpringBoot篇。

**箭头方向** = 前置依赖关系，即 A → B 表示**先学 A 再学 B**。

## 🎯 学习建议

1. **Phase 1 是根基**：[[Java基础与进阶篇]] 内容最多（1400+ 行），覆盖了集合、并发、JUC 等核心考点，建议 **反复翻阅 2~3 遍**
2. **Phase 2 深化理解**：[[JVM篇]] 篇幅不长但概念密集，建议结合 [[Java基础与进阶篇]] 中的内存相关内容同步学习
3. **Phase 3 实战为主**：[[SpringBoot篇]] → [[登录认证篇]] / [[SpringCloud篇]]，建议边学边动手搭建项目
4. **面试导向**：集合、并发、JVM 是 Java 面试**最高频**的三大板块，分别分布在笔记 ① 和 ② 中
