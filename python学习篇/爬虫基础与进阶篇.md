# 爬虫基础与进阶篇

## 一、爬虫概述

### 什么是网络爬虫

**网络爬虫（Web Crawler / Spider）** 是一种自动化的程序或脚本，按照一定规则批量抓取互联网上的信息。

```
用户浏览器 ──→ 发送请求 ──→ 网站服务器
                              │
爬虫程序 ──→ 发送请求 ──→ 返回 HTML/JSON/其他
            解析提取 ←────┘
            清洗存储到本地
```

| 术语 | 说明 |
|:----:|------|
| **URL** | 统一资源定位符，标识资源位置 |
| **请求（Request）** | 客户端向服务器索要数据 |
| **响应（Response）** | 服务器返回的数据内容 |
| **解析（Parse）** | 从响应中提取所需信息 |
| **UA（User-Agent）** | 请求头中的用户代理标识 |

### 爬虫的分类

| 类型 | 特点 | 工具 | 适用场景 |
|:----:|------|:----:|:--------:|
| **通用爬虫** | 全网范围抓取，规模大 | Scrapy、Nutch | 搜索引擎（Google、百度） |
| **聚焦爬虫** | 特定主题/站点 | requests + BS4 | 商品价格、新闻采集 |
| **增量爬虫** | 只抓取新/变更内容 | Scrapy + Redis | 监控类需求 |
| **深层爬虫** | 需登录/表单提交 | Selenium、Playwright | 需要交互的站点 |

### 爬虫合法性与伦理 ⚠️

> [!warning] **爬虫三大红线**
> 1. **遵守 robots.txt**：检查 `https://example.com/robots.txt` 了解允许爬取的内容
> 2. **控制频率**：不要对服务器造成压力（建议 1~3 秒间隔）
> 3. **不碰敏感数据**：不抓取用户隐私、版权内容、需付费内容

```python
# 查看 robots.txt 示例
# User-agent: *
# Disallow: /admin/       ← 不允许爬取 admin 路径
# Disallow: /api/
# Allow: /public/
# Crawl-delay: 10         ← 建议每次请求间隔 10 秒
```

> [!tip] **合法爬虫四原则**
> 1. 爬取公开数据，不绕过登录/验证
> 2. 控制请求频率，不造成服务器压力
> 3. 标识爬虫身份（设置有意义的 User-Agent）
> 4. 抓取的数据不用于侵权/违法用途

## 二、HTTP 基础与 Requests 库

### HTTP 请求方法

| 方法 | 说明 | 爬虫常用 |
|:----:|------|:--------:|
| `GET` | 获取资源（参数在 URL 中） | ⭐ 最常用 |
| `POST` | 提交数据（参数在请求体中） | ⭐ 登录、表单 |
| `PUT` | 更新资源 | 极少 |
| `DELETE` | 删除资源 | 极少 |
| `HEAD` | 仅获取响应头 | 检查链接有效性 |

### HTTP 状态码

| 状态码 | 含义 | 爬虫应对 |
|:------:|------|:--------:|
| **200** | OK，成功 | ✅ 正常解析 |
| **301/302** | 重定向 | ✅ 自动跟随（requests 默认） |
| **403** | Forbidden，禁止访问 | ❌ 被封了，换代理/加 headers |
| **404** | Not Found | ❌ 页面不存在 |
| **429** | Too Many Requests | ❌ 请求太频繁，等待后重试 |
| **500/502/503** | 服务器错误 | ⏳ 服务器压力大，稍后重试 |

### Requests 库 ⭐

安装：`pip install requests`

#### GET 请求

```python
import requests

# ⭐ 基本 GET
response = requests.get("https://httpbin.org/get")
print(response.status_code)    # 200
print(response.text)           # HTML 内容（字符串）
print(response.content)        # 二进制内容（图片等）
print(response.encoding)       # 编码（可修改）

# ⭐ 带参数（params）
params = {"q": "python爬虫", "page": 1, "size": 20}
response = requests.get("https://httpbin.org/get", params=params)
# 实际请求: https://httpbin.org/get?q=python爬虫&page=1&size=20
print(response.url)           # 实际请求的 URL

# ⭐ 带请求头（headers）
headers = {
    "User-Agent": "Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36 "
                  "(KHTML, like Gecko) Chrome/120.0.0.0 Safari/537.36",
    "Accept": "text/html,application/xhtml+xml,application/xml;q=0.9,*/*;q=0.8",
    "Accept-Language": "zh-CN,zh;q=0.9,en;q=0.8",
    "Referer": "https://www.google.com/",
}
response = requests.get("https://httpbin.org/headers", headers=headers)

# ⭐ 超时（必须设置！）
response = requests.get("https://httpbin.org/delay/3", timeout=10)
# timeout 可以是元组: (连接超时, 读取超时)
response = requests.get("https://httpbin.org/delay/3", timeout=(5, 10))
```

#### POST 请求

```python
import requests

# 表单数据（Content-Type: application/x-www-form-urlencoded）
```

#### Cookie 与会话（Session）⭐

```python
import requests

# 方式一：手动携带 Cookie
cookies = {"session_id": "abc123", "token": "xxx"}
response = requests.get("https://httpbin.org/cookies", cookies=cookies)

# 方式二：从响应中获取并携带
response = requests.get("https://example.com/login")
my_cookies = response.cookies
response2 = requests.get("https://example.com/dashboard", cookies=my_cookies)

# ⭐ 方式三：Session（推荐！自动管理 Cookie）
session = requests.Session()
session.headers.update({"User-Agent": "Mozilla/5.0 ..."})

# 登录（Cookie 自动保存到 session 中）
session.post("https://example.com/login", data={"user": "admin", "pass": "123"})

# 后续请求自动携带 Cookie
response = session.get("https://example.com/dashboard")
response2 = session.get("https://example.com/profile")
```

#### 响应处理

```python
import requests

response = requests.get("https://httpbin.org/json")

# 常见操作
response.text                    # 响应体（字符串）
response.content                 # 响应体（字节）
response.json()                  # 解析 JSON（当 API 返回 JSON 时）
response.status_code             # 状态码
response.headers                 # 响应头（字典）
response.headers.get("Set-Cookie")  # 获取特定响应头
response.cookies                 # CookieJar
response.url                     # 最终 URL（重定向后）
response.elapsed.total_seconds() # 响应耗时（秒）
response.encoding                # 编码
response.encoding = "utf-8"      # 修改编码（解决乱码）
response.raise_for_status()      # 状态码 >= 400 时抛出异常

# ⭐ 处理 JSON API（最常见的场景）
data = response.json()           # 自动解析 JSON
print(data["key"])
```

#### 异常处理

```python
import requests
from requests.exceptions import RequestException, Timeout, ConnectionError

try:
    response = requests.get("https://httpbin.org/delay/5", timeout=3)
    response.raise_for_status()
except Timeout:
    print("请求超时")
except ConnectionError:
    print("网络连接错误")
except RequestException as e:
    print(f"请求异常: {e}")
else:
    print(f"成功，状态码: {response.status_code}")

# 常见异常类型
# - requests.ConnectionError    : 网络不通/DNS 解析失败
# - requests.Timeout            : 超时
# - requests.HTTPError          : HTTP 错误状态码（配合 raise_for_status）
# - requests.TooManyRedirects   : 重定向次数过多
# - requests.RequestException   : 以上所有异常的基类
```

> [!tip] **Requests 最佳实践**
> - **永远设置 timeout**，否则可能永远挂起
> - **用 Session** 管理 Cookie 和默认 headers
> - **设置合理的 User-Agent**，不要用默认的 `python-requests`
> - **养成检查 status_code 的习惯**
> - `.json()` 会自动解码，比 `.text` + `json.loads` 更方便

```python
from bs4 import BeautifulSoup

html = """
<html>
  <body>
    <h1 class="title">爬虫教程</h1>
    <div id="content">
      <ul class="list">
        <li class="item active">Python</li>

# find_parent / find_next_sibling — 导航
li = soup.find("li", class_="active")
parent_ul = li.find_parent("ul")             # 父元素
next_item = li.find_next_sibling("li")       # 下一个兄弟
```

### 3.3 lxml + XPath（高效方案）

安装：`pip install lxml`

```python
from lxml import html

page = requests.get("https://httpbin.org/html")
tree = html.fromstring(page.content)

# ⭐ XPath — 功能最强大的选择器
title = tree.xpath("//h1/text()")              # 所有 h1 文本
first_h1 = tree.xpath("//h1/text()")[0]        # 第一个 h1
links = tree.xpath("//a/@href")                 # 所有链接

# XPath 常见语法
# //div         : 所有 div
# //div[@id]    : 有 id 属性的 div
# //div[@class="title"] : class="title" 的 div
# //div[@id="content"]/p  : id="content" 下直接子标签 p
# //div//p      : div 下所有 p（任意层级）
# //ul/li[1]    : ul 下第一个 li
# //ul/li[last()] : 最后一个 li
# //a[contains(@href, "page")]  : href 包含 "page"
# //span[starts-with(@class, "price")]  : class 以 "price" 开头

# ⭐ 综合提取
for item in tree.xpath("//ul[@class='list']/li"):
    text = item.xpath("text()")[0] if item.xpath("text()") else ""
    class_name = item.get("class", "")
    print(f"{class_name}: {text}")
```

### 选择器对比

| 对比 | 正则 | BeautifulSoup | XPath |
|:----:|:----:|:-------------:|:-----:|
| **学习曲线** | 陡峭 | 平缓 ⭐ | 中等 |
| **性能** | 快 | 中 | 快 ⭐ |
| **容错性** | 差（格式变了就垮） | 好 ⭐ | 中 |
| **推荐场景** | 简单文本提取 | **日常爬虫首选** ⭐ | 复杂嵌套 DOM |

> [!tip] **推荐组合**
> - **简单页面**：requests + BeautifulSoup（CSS 选择器）
> - **复杂页面**：requests + lxml（XPath）
> - **动态页面**：Selenium/Playwright + BeautifulSoup

## 四、数据提取实战

### 提取表格数据

```python
import requests
from bs4 import BeautifulSoup

response = requests.get("https://example.com/table")
soup = BeautifulSoup(response.text, "lxml")

table = soup.find("table")
headers = [th.text.strip() for th in table.find_all("th")]
rows = []

for tr in table.find_all("tr")[1:]:  # 跳过表头
    cells = tr.find_all("td")
    row = [cell.text.strip() for cell in cells]
    rows.append(row)

print(headers)   # ['姓名', '年龄', '城市']
print(rows)      # [['张三', '28', '北京'], ['李四', '25', '上海']]
```

### 提取 JSON 数据

```python
# 很多网站将数据隐藏在 <script> 标签中的 JSON 里
import re
import json
from bs4 import BeautifulSoup

html = """
<script id="__NEXT_DATA__" type="application/json">
{"props":{"pageProps":{"products":[{"id":1,"name":"iPhone","price":6999},{"id":2,"name":"MacBook","price":12999}]}}}
</script>
"""

soup = BeautifulSoup(html, "lxml")
script = soup.find("script", id="__NEXT_DATA__")
if script:
    data = json.loads(script.string)          # 解析 JSON
    products = data["props"]["pageProps"]["products"]
    for p in products:
        print(p["name"], p["price"])

# 从页面中直接提取 JSON 片段
match = re.search(r"window\.__INITIAL_STATE__\s*=\s*({.*?});", html)
if match:
    data = json.loads(match.group(1))
```

### 翻页处理 ⭐

```python
import requests
from bs4 import BeautifulSoup

# 方式一：URL 参数翻页（最常见）
def crawl_pages(base_url: str, max_pages: int = 10):
    for page in range(1, max_pages + 1):
        url = f"{base_url}?page={page}"
        response = requests.get(url, headers=headers, timeout=10)
        if response.status_code != 200:
            break
        yield response.text

# 方式二：点击"下一页"链接
def crawl_next_page(start_url: str, max_pages: int = 10):
    url = start_url
    for _ in range(max_pages):
        response = requests.get(url, headers=headers, timeout=10)
        soup = BeautifulSoup(response.text, "lxml")

        # 提取当前页数据
        yield soup

        # 查找"下一页"链接
        next_link = soup.select_one("a.next")
        if not next_link:
            break
        next_href = next_link.get("href")
        url = f"https://example.com{next_href}"  # 拼接完整 URL

# 方式三：API 接口翻页（用参数控制）
def crawl_api(api_url: str, page_size: int = 20):
    page = 1
    while True:
        response = requests.get(f"{api_url}?page={page}&size={page_size}", timeout=10)
        if response.status_code != 200:
            break
        data = response.json()
        if not data["items"]:       # 没有更多数据
            break
        yield data["items"]
        page += 1
```

### 5.1 Selenium

安装：`pip install selenium`

```python
from selenium import webdriver
from selenium.webdriver.common.by import By
from selenium.webdriver.common.keys import Keys
from selenium.webdriver.support.ui import WebDriverWait
from selenium.webdriver.support import expected_conditions as EC
from selenium.webdriver.chrome.options import Options
import time

# ⭐ 配置无头浏览器
options = Options()
# options.add_argument("--headless=new")          # 无界面模式（服务器部署）
options.add_argument("--disable-gpu")
options.add_argument("--no-sandbox")
options.add_argument("--disable-dev-shm-usage")
options.add_argument("--window-size=1920,1080")
options.add_argument(
    "user-agent=Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36 "
    "(KHTML, like Gecko) Chrome/120.0.0.0 Safari/537.36"
)

# 启动浏览器
driver = webdriver.Chrome(options=options)

try:
    # 访问页面
    driver.get("https://example.com")
    driver.set_page_load_timeout(30)

    # ⭐ 显式等待（等待元素出现）
    wait = WebDriverWait(driver, 10)
    element = wait.until(
        EC.presence_of_element_located((By.CLASS_NAME, "item"))
    )

    # 查找元素
    # By.ID / By.CLASS_NAME / By.TAG_NAME / By.CSS_SELECTOR / By.XPATH
    title = driver.find_element(By.CSS_SELECTOR, "h1.title")
    print(title.text)

    items = driver.find_elements(By.CLASS_NAME, "item")
    for item in items:
        print(item.text)

    # 模拟操作
    search_box = driver.find_element(By.NAME, "q")
    search_box.send_keys("爬虫教程")
    search_box.send_keys(Keys.RETURN)

    # 滚动（懒加载）
    driver.execute_script("window.scrollTo(0, document.body.scrollHeight);")
    time.sleep(2)

    # 获取页面源代码（之后可以用 BeautifulSoup 解析）
    html = driver.page_source

finally:
    driver.quit()   # 必须关闭！
```

## 六、异步爬虫（aiohttp）

### 同步 vs 异步对比

```python
import asyncio
import aiohttp
import requests
import time

# 同步方式 — 串行，慢
def sync_fetch(urls: list[str]):
    results = []
    for url in urls:
        response = requests.get(url, timeout=10)
        results.append(response.text)
    return results

# 异步方式 — 并发，快 ⭐
async def async_fetch_one(session: aiohttp.ClientSession, url: str) -> str:
    async with session.get(url) as response:
        return await response.text()

async def async_fetch(urls: list[str]):
    async with aiohttp.ClientSession() as session:
        tasks = [async_fetch_one(session, url) for url in urls]
        return await asyncio.gather(*tasks)

# 性能实测（10 个 URL）
# 同步: ~8 秒
# 异步: ~1 秒
```

```python
import aiohttp
from aiohttp import ClientTimeout, ClientSession

# ⭐ 单个请求
async def fetch(url: str) -> str:
    timeout = ClientTimeout(total=30)
    headers = {"User-Agent": "Mozilla/5.0 ..."}

    async with ClientSession(timeout=timeout, headers=headers) as session:
        async with session.get(url) as response:
            response.raise_for_status()
            return await response.text()     # 获取文本
            # return await response.json()   # 获取 JSON
            # return await response.read()   # 获取二进制

async def crawl_urls(urls: list[str]):
    timeout = ClientTimeout(total=30)
    headers = {"User-Agent": "Mozilla/5.0 ..."}

    async with ClientSession(timeout=timeout, headers=headers) as session:
        tasks = []
        for url in urls:
            task = asyncio.create_task(fetch_one(session, url))
            tasks.append(task)

        results = await asyncio.gather(*tasks, return_exceptions=True)
        # return_exceptions=True 让个别失败不阻塞整体

        success = []
        for url, result in zip(urls, results):
            if isinstance(result, Exception):
                print(f"{url} 失败: {result}")
            else:
                success.append(result)
        return success

async def fetch_one(session: ClientSession, url: str) -> str:
    try:
        async with session.get(url) as response:
            return await response.text()
    except Exception as e:
        raise e
```

```python
import asyncio
import aiohttp
from bs4 import BeautifulSoup
from aiohttp import ClientTimeout

async def fetch_and_parse(session: aiohttp.ClientSession, url: str) -> dict:
    try:
        async with session.get(url) as response:
            html = await response.text()

        soup = BeautifulSoup(html, "lxml")
        title = soup.find("h1")
        return {
            "url": url,
            "title": title.text.strip() if title else "",
            "status": response.status,
        }
    except Exception as e:
        return {"url": url, "error": str(e)}

async def crawl(urls: list[str]):
    timeout = ClientTimeout(total=30)
    headers = {"User-Agent": "Mozilla/5.0 ..."}

    async with aiohttp.ClientSession(timeout=timeout, headers=headers) as session:
        tasks = [fetch_and_parse(session, url) for url in urls]
        results = await asyncio.gather(*tasks)
        return results

# 控制并发数（Semaphore）
async def crawl_with_limit(urls: list[str], max_concurrent: int = 5):
    semaphore = asyncio.Semaphore(max_concurrent)

    async def bounded_fetch(url: str):
        async with semaphore:
            return await fetch_and_parse(session, url)

    timeout = ClientTimeout(total=30)
    async with aiohttp.ClientSession(timeout=timeout) as session:
        tasks = [bounded_fetch(url) for url in urls]
        return await asyncio.gather(*tasks)
```

### 异步爬虫完整流程

```python
import asyncio
import aiohttp
from bs4 import BeautifulSoup
import json

class AsyncCrawler:
    """异步爬虫示例"""

    def __init__(self, max_concurrent: int = 10):
        self.semaphore = asyncio.Semaphore(max_concurrent)
        self.results = []
        self.session = None

    async def __aenter__(self):
        timeout = aiohttp.ClientTimeout(total=30)
        headers = {"User-Agent": "Mozilla/5.0 ..."}
        self.session = aiohttp.ClientSession(timeout=timeout, headers=headers)
        return self

    async def __aexit__(self, *args):
        await self.session.close()

    async def fetch(self, url: str) -> str:
        async with self.semaphore:          # 控制并发
            async with self.session.get(url) as response:
                return await response.text()

    async def parse(self, url: str, html: str) -> dict:
        soup = BeautifulSoup(html, "lxml")
        title = soup.find("h1")
        return {
            "url": url,
            "title": title.text.strip() if title else "",
        }

    async def crawl(self, urls: list[str]):
        tasks = []
        for url in urls:
            tasks.append(self.process_url(url))

        await asyncio.gather(*tasks)
        return self.results

    async def process_url(self, url: str):
        try:
            html = await self.fetch(url)
            data = await self.parse(url, html)
            self.results.append(data)
            print(f"✅ {url}")
        except Exception as e:
            print(f"❌ {url}: {e}")

# 使用
async def main():
    urls = [f"https://httpbin.org/html" for _ in range(10)]

    async with AsyncCrawler(max_concurrent=5) as crawler:
        results = await crawler.crawl(urls)

    with open("results.json", "w", encoding="utf-8") as f:
        json.dump(results, f, ensure_ascii=False, indent=2)

asyncio.run(main())
```

> [!tip] **异步爬虫优势**
> - IO 密集型任务（网络请求）并发效率极高
> - 配合 `asyncio.Semaphore` 精确控制并发数
> - 比多线程更轻量，可轻松启动数百个并发
> - **注意**：解析部分最好用同步库（BS4 不支持 async）

### ⭐ 请求频率控制

```python
import time
import random
from functools import wraps

# 方式一：简单 sleep
for url in urls:
    response = requests.get(url, headers=headers)
    time.sleep(random.uniform(1, 3))        # 随机延迟 1~3 秒

# 方式二：装饰器限制频率
def rate_limit(min_interval: float = 2.0):
    last_called = [0.0]

    def decorator(func):
        @wraps(func)
        def wrapper(*args, **kwargs):
            elapsed = time.perf_counter() - last_called[0]
            if elapsed < min_interval:
                time.sleep(min_interval - elapsed)
            last_called[0] = time.perf_counter()
            return func(*args, **kwargs)
        return wrapper
    return decorator

@rate_limit(min_interval=1.5)
def fetch(url: str):
    return requests.get(url, headers=headers)

# 方式三：指数退避（遇到 429 时）
def fetch_with_retry(url: str, max_retries: int = 5):
    for attempt in range(max_retries):
        response = requests.get(url, headers=headers)
        if response.status_code == 429:
            wait = 2 ** attempt + random.random()
            print(f"429，等待 {wait:.1f} 秒后重试...")
            time.sleep(wait)
            continue
        return response
    raise Exception(f"重试 {max_retries} 次后仍然失败: {url}")
```

```python
        # GET 请求
        for url in self.start_urls:
            yield scrapy.Request(url, callback=self.parse)

        # POST 请求（登录等）
        yield FormRequest(
            url="https://example.com/login",
            form_data={"username": "admin", "password": "123"},
            callback=self.after_login,
        )

    def after_login(self, response):
        if "登录成功" in response.text:
            self.logger.info("登录成功")
            yield scrapy.Request(
                "https://example.com/protected",
                callback=self.parse,
            )

    # ⭐ 自定义参数（通过 -a 传递）
    # scrapy crawl books -a category=python
    def __init__(self, category=None, *args, **kwargs):
        super().__init__(*args, **kwargs)
        self.category = category
```

```python
            "INSERT OR IGNORE INTO books VALUES (?, ?, ?, ?)",
            (item.get("title"), item.get("price"),
             item.get("author"), item.get("url")),
        )
```

### 字体反爬

某些网站使用自定义字体（WOFF）混淆数字/文字，肉眼看起来正常但 HTML 中是乱码：

```python
# 思路：下载字体文件 → 解析字符映射 → 替换
from fontTools.ttLib import TTFont
import requests

# 下载字体文件
font_resp = requests.get("https://example.com/custom.woff")
with open("font.woff", "wb") as f:
    f.write(font_resp.content)

# 解析字体映射
font = TTFont("font.woff")
cmap = font.getBestCmap()

# cmap 示例: {0x4eac: 'one', 0x4ead: 'two', ...}
# 需要建立字形名 → 实际字符的映射
glyph_map = {"one": "1", "two": "2", "three": "3", ...}

def decode_font_text(encoded_text: str) -> str:
    """解密字体混淆文本"""
    result = ""
    for char in encoded_text:
        code = ord(char)
        glyph_name = cmap.get(code, "")
        real_char = glyph_map.get(glyph_name, char)
        result += real_char
    return result
```

### 请求参数加密（签名）

```python
import hashlib
import time
import requests

# 某些 API 需要签名参数（常见于电商、出行平台）
def generate_sign(params: dict, secret: str) -> str:
    """生成签名（模拟常见算法）"""
    # 1. 按 key 排序
    sorted_keys = sorted(params.keys())
    # 2. 拼接 key=value
    query = "&".join(f"{k}={params[k]}" for k in sorted_keys)
    # 3. 拼接密钥
    raw = query + "&secret=" + secret
    # 4. MD5 或其他哈希
    return hashlib.md5(raw.encode()).hexdigest()

def fetch_with_sign(url: str, params: dict, secret: str):
    params["timestamp"] = int(time.time())     # 时间戳
    params["sign"] = generate_sign(params, secret)
    return requests.get(url, params=params)
```

### 实战：爬取豆瓣电影 Top250

```python
import requests
from bs4 import BeautifulSoup
import csv
import time
import random

HEADERS = {
    "User-Agent": "Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36 "
                  "(KHTML, like Gecko) Chrome/120.0.0.0 Safari/537.36",
    "Accept": "text/html,application/xhtml+xml,application/xml;q=0.9,*/*;q=0.8",
    "Accept-Language": "zh-CN,zh;q=0.9,en;q=0.8",
}

BASE_URL = "https://movie.douban.com/top250"

def parse_page(html: str) -> list[dict]:
    """解析一页 HTML，提取电影信息"""
    soup = BeautifulSoup(html, "lxml")
    movies = []

    for item in soup.select("div.item"):
        title = item.select_one("span.title").text
        rating = item.select_one("span.rating_num").text
        quote_el = item.select_one("span.inq")
        quote = quote_el.text if quote_el else ""

        # 提取其他信息
        info = item.select_one("p").text.strip()
        # 提取年份/国家/类型等
        parts = info.split("\n")[0].strip().split("\xa0/\xa0")

        movies.append({
            "title": title,
            "rating": float(rating),
            "quote": quote,
            "year": parts[0] if len(parts) > 0 else "",
            "country": parts[1] if len(parts) > 1 else "",
            "genre": parts[2] if len(parts) > 2 else "",
        })

    return movies

def crawl_douban_top250() -> list[dict]:
    """爬取豆瓣 Top250 全部数据"""
    all_movies = []

    for page in range(10):         # 共 10 页，每页 25 部
        url = f"{BASE_URL}?start={page * 25}&filter="
        print(f"正在爬取第 {page + 1} 页...")

        try:
            response = requests.get(url, headers=HEADERS, timeout=10)
            response.raise_for_status()

            # 检测编码
            response.encoding = "utf-8"

            movies = parse_page(response.text)
            all_movies.extend(movies)
            print(f"  第 {page + 1} 页完成，获取 {len(movies)} 部电影")

        except requests.RequestException as e:
            print(f"  第 {page + 1} 页失败: {e}")

        # 随机延迟（礼貌爬虫）
        if page < 9:     # 最后 1 页不用等
            time.sleep(random.uniform(1, 2))

    return all_movies

def save_to_csv(movies: list[dict], filename: str = "douban_top250.csv"):
    """保存到 CSV"""
    with open(filename, "w", newline="", encoding="utf-8-sig") as f:
        writer = csv.DictWriter(f, fieldnames=["title", "rating", "quote", "year", "country", "genre"])
        writer.writeheader()
        writer.writerows(movies)
    print(f"数据已保存到 {filename}")

if __name__ == "__main__":
    movies = crawl_douban_top250()
    save_to_csv(movies)
    print(f"总共爬取 {len(movies)} 部电影")

    # 输出统计
    avg_rating = sum(m["rating"] for m in movies) / len(movies)
    print(f"平均评分: {avg_rating:.2f}")
    print(f"最高评分: {max(m["rating"] for m in movies)}")
    print(f"最低评分: {min(m["rating"] for m in movies)}")
```

### 实战：异步爬取 API 数据（更通用的模式）

```python
import asyncio
import aiohttp
import json
import csv
from dataclasses import dataclass

@dataclass
class Repository:
    """GitHub 仓库信息"""
    name: str
    owner: str
    stars: int
    forks: int
    language: str | None
    description: str | None

class GitHubCrawler:
    """异步爬取 GitHub 热门仓库"""
    API_BASE = "https://api.github.com"
    HEADERS = {
        "Accept": "application/vnd.github.v3+json",
        "User-Agent": "AsyncCrawler/1.0",
    }

    def __init__(self, max_concurrent: int = 10):
        self.semaphore = asyncio.Semaphore(max_concurrent)

    async def fetch_repos(self, language: str, page: int = 1) -> list[dict]:
        """获取一页仓库数据"""
        url = f"{self.API_BASE}/search/repositories"
        params = {
            "q": f"language:{language}",
            "sort": "stars",
            "order": "desc",
            "per_page": 30,
            "page": page,
        }

        async with aiohttp.ClientSession(headers=self.HEADERS) as session:
            async with self.semaphore:
                async with session.get(url, params=params) as resp:
                    if resp.status != 200:
                        print(f"API 错误: {resp.status}")
                        return []
                    data = await resp.json()
                    return data.get("items", [])

    async def crawl_language(self, language: str, max_pages: int = 5) -> list[Repository]:
        """爬取某语言的热门仓库"""
        repos = []

        tasks = [self.fetch_repos(language, page) for page in range(1, max_pages + 1)]
        results = await asyncio.gather(*tasks)

        for page_items in results:
            for item in page_items:
                repos.append(Repository(
                    name=item["name"],
                    owner=item["owner"]["login"],
                    stars=item["stargazers_count"],
                    forks=item["forks_count"],
                    language=item["language"],
                    description=item["description"],
                ))

        repos.sort(key=lambda r: r.stars, reverse=True)
        return repos

    async def crawl_multiple(self, languages: list[str]) -> dict[str, list[Repository]]:
        """爬取多种语言的热门仓库"""
        tasks = [self.crawl_language(lang) for lang in languages]
        results = await asyncio.gather(*tasks)
        return dict(zip(languages, results))

async def main():
    crawler = GitHubCrawler(max_concurrent=5)

    languages = ["python", "javascript", "rust", "go", "typescript"]
    results = await crawler.crawl_multiple(languages)

    for lang, repos in results.items():
        print(f"\n=== {lang.upper()} 热门仓库 ===")
        for repo in repos[:5]:
            print(f"  ⭐ {repo.stars:>6} | {repo.owner}/{repo.name}")

if __name__ == "__main__":
    asyncio.run(main())
```

## 十二、爬虫常见问题排查

### 请求类问题

| 问题 | 常见原因 | 解决 |
|:----:|:--------:|:-----|
| **403 Forbidden** | UA 被识别 / IP 被封 | 换 UA + 换代理 |
| **429 Too Many Requests** | 请求太频繁 | 增加延迟、指数退避 |
| **502 Bad Gateway** | 目标服务器压力大 | 重试几次 |
| **SSL 错误** | 证书验证失败 | `verify=False`（谨慎） |
| **连接超时** | 网络问题 / IP 被墙 | 换网络/代理 |
| **中文乱码** | 编码不对 | 设置 `response.encoding = "utf-8"` |
