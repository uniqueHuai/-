## 📚 推荐学习顺序

### Phase 1：基础理论（概念层）

先建立对 AI Agent 的整体认知，理解底层原理。

#### ① [[AIAgent篇/AI Agent 概述|AI Agent 概述]] ⭐ 起点

| 项目 | 说明 |
|:----|:----|
| **前置知识** | 无 |
| **内容** | Agent 定义、与传统程序区别、发展历程、核心能力（感知/推理/行动） |
| **一句话** | **整个 AI Agent 系列的入口，从这里开始** |

---

#### ② [[AIAgent篇/LLM 原理与选型|LLM 原理与选型]]

| 项目 | 说明 |
|:----|:----|
| **前置知识** | ① |
| **内容** | Transformer 原理、Token/Context Window/Temperature 概念、主流模型对比与选型策略 |
| **一句话** | 理解 LLM 的工作原理，才能更好地设计 Agent |

---

#### ③ [[AIAgent篇/Prompt Engineering|Prompt Engineering]]

| 项目 | 说明 |
|:----|:----|
| **前置知识** | ②（了解 LLM 基础即可） |
| **内容** | Prompt 结构、编写技巧、高级模式（Chain-of-Thought、Few-Shot）、System Prompt 设计 |
| **一句话** | Prompt 是操控 LLM 的"指令语言"，是 Agent 开发最基础的技能 |

---

### Phase 2：核心技术（机制层）

Agent 的核心技术组件——让 LLM 能调用工具、检索知识、拥有记忆。

#### ④ [[AIAgent篇/Function Calling|Function Calling]] ⭐ Agent 基石

| 项目 | 说明 |
|:----|:----|
| **前置知识** | ②、③ |
| **内容** | Function Calling 原理、Tool 定义与注册、参数解析、流式与非流式调用 |
| **一句话** | **Function Calling 是 Agent 与外部世界交互的核心机制**，必须掌握 |

---

#### ⑤ [[AIAgent篇/RAG 检索增强生成|RAG 检索增强生成]]

| 项目 | 说明 |
|:----|:----|
| **前置知识** | ② |
| **内容** | RAG 架构、向量检索、Chunking 策略、Embedding 模型、检索质量优化 |
| **一句话** | 解决 LLM 知识固化问题，让 Agent 拥有实时检索外部知识的能力 |

---

#### ⑥ [[AIAgent篇/Memory 与上下文管理|Memory 与上下文管理]]

| 项目 | 说明 |
|:----|:----|
| **前置知识** | ①、④ |
| **内容** | 短期记忆（Token 窗口）、长期记忆（向量库）、工作记忆、上下文窗口优化策略 |
| **一句话** | Agent 的记忆系统决定了它能"记住"多远的过去 |

---

### Phase 3：进阶架构（架构层）

从单 Agent 走向复杂系统架构。

#### ⑦ [[AIAgent篇/MCP 协议|MCP 协议]] ⭐ 行业标准

| 项目 | 说明 |
|:----|:----|
| **前置知识** | ④（理解 Tool 概念） |
| **内容** | MCP 协议定义、架构（Host/Client/Server）、JSON-RPC 通信、工具发现机制 |
| **一句话** | **MCP 是 2026 年 AI Agent 工具集成的行业标准协议** |

---

#### ⑧ [[AIAgent篇/Skill 技能机制|Skill 技能机制]]

| 项目 | 说明 |
|:----|:----|
| **前置知识** | ④、⑦ |
| **内容** | Skill 定义、与 Tool 的关系、Skill 分组与管理、复用与共享 |
| **一句话** | Skill 是对 Tool 的更高层抽象，实现能力的按领域分组和复用 |

---

#### ⑨ [[AIAgent篇/Multi-Agent 系统|Multi-Agent 系统]]

| 项目 | 说明 |
|:----|:----|
| **前置知识** | ①、④ |
| **内容** | 多 Agent 架构、角色分工、通信协议、协调机制、冲突解决 |
| **一句话** | 多个专业 Agent 分工协作，比单 Agent 更适合复杂任务 |

---

#### ⑩ [[AIAgent篇/Agentic RAG 实战|Agentic RAG 实战]]

| 项目 | 说明 |
|:----|:----|
| **前置知识** | ⑤、①（RAG + Agent 融合） |
| **内容** | Agent 自主决策是否检索、多步检索、检索质量评估、反思与追问 |
| **一句话** | 让 Agent 自主决定"何时检索、检索什么、是否重新检索" |

## 🎯 学习建议

### 按角色选择

| 你的角色 | 推荐路线 |
|:--------|:---------|
| **Java 后端** | ① → ② → ③ → ④ → ⑤ → ⑥ → ⑦ → ⑧ → **⑪ Spring AI** |
| **架构师** | ① → ② → ③ → ④ → ⑤ → ⑦ → ⑧ → ⑨ → ⑩ |
| **全栈/入门** | ① → ② → ③ → ④ → ⑤ → ⑪ → ⑬ → ⑭ |
| **安全关注者** | ① → ② → ④ → ⑦ → **⑮ 安全** → **⑯ 监控** |

### 关键路径

- **最短路径**（搭建一个能用的 Agent）：① → ② → ③ → ④ → ⑪
- **核心路径**（完整 Agent 开发）：① → ② → ③ → ④ → ⑤ → ⑥ → ⑦ → ⑧ → ⑪
- **高阶路径**（生产级复杂系统）：核心路径 + ⑨ → ⑩ → ⑮ → ⑯
- **三阶段"了解即可"**：⑫ LangChain4j（备选框架）、⑬ Python 框架速览、⑭ 本地部署
